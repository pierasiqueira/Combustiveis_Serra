# Painel de Monitoramento de Combustíveis — Serra/ES

Um painel web iterativo desenvolvido para pesquisa, visualização gráfica e análise estatística dos preços de combustíveis no município de Serra - ES. Este projeto faz parte do entregável da **AOP3**.
Disciplina: Arquitetura de Dados Relacionais
Curso: Análise e Desenvolvimento de Sistemas
Universidade de Vila Velha (UVV)

---

## Funcionalidades

- **Visualização Gráfica:** Gráficos interativos apresentando a evolução do preço médio por combustível e a média de preço por posto de gasolina.
- **Consultas SQL:** Área dedicada para exibição e documentação das consultas utilizadas na análise de dados.
- **Tabela Dinâmica:** Listagem detalhada dos preços para fácil consulta e comparação.
- **Interface Responsiva:** Layout adaptado para navegação em dispositivos móveis e desktop.

---

## Tecnologias Utilizadas

- **HTML5 & CSS3** — Estruturação e estilização customizada
- **Bootstrap 5** — Framework para layout responsivo e componentes
- **JavaScript (ES6+)** — Manipulação de dados e renderização dos gráficos
- **Chart.js** *(ou biblioteca de gráficos utilizada)* — Geração dos gráficos dinâmicos
- **Vercel** — Hospedagem e deploy contínuo da aplicação
